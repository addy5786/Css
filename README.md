# HTML and CSS Practical Assignments

## 📌 About the Project
This repository contains 14 practical assignments designed to learn and practice the fundamentals of HTML and CSS. The exercises cover inline, internal, and external CSS, selectors, gradients, backgrounds, typography, the CSS box model, and positioning properties.

## 🎯 Objectives
- Understand HTML document structure.
- Apply CSS using inline, internal, and external stylesheets.
- Learn CSS selectors, including class, ID, and universal selectors.
- Work with text shadows, gradients, and background images.
- Understand typography and text formatting.
- Practice the CSS box model and positioning techniques.
- Create visually appealing and responsive webpage elements.

## 📝 Assignments Included

| No. | Assignment | Concepts Covered |
|---|---|---|
| 1 | Styled Div Elements | Inline CSS, background colors, text colors, padding, margin |
| 2 | Internal CSS Styling | Internal stylesheet, headings, paragraphs, buttons |
| 3 | Text Shadow | Text-shadow, offset, blur radius, color |
| 4 | External CSS | Linking HTML and CSS files |
| 5 | Class Selectors | Classes, background colors, font sizes |
| 6 | ID Selector | Unique element styling, IDs vs. classes |
| 7 | Website Banner | Linear/conic gradients, header styling |
| 8 | Universal Selector | Universal selector, font size, line height |
| 9 | Gradient Boxes | Linear gradients, radial gradients |
| 10 | Background Image | Background-repeat, background-position |
| 11 | Background Video | HTML video, autoplay, loop, muted |
| 12 | Text Formatting | Font families, sizes, styles, weights, decorations, transformations |
| 13 | CSS Box Model | Width, height, border, padding, margin, outline |
| 14 | CSS Positioning | Fixed, relative, absolute, sticky, static positioning |

## 🛠️ Technologies Used
- **HTML5** – For webpage structure and content.
- **CSS3** – For styling, layouts, colors, gradients, and positioning.

## 🚀 How to Run
1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open any assignment's HTML file in your browser.
4. Alternatively, install the Live Server extension in VS Code and select **Open with Live Server**.
